FileSync プライバシーポリシー

最終更新日: 2026年10月29日 / 初版発行: 2026年5月3日

要約: FileSync は広告・追跡を行いません。ファイル転送は選択した接続先と直接行い、認証情報はその接続の認証に使用します。 認証情報には OS のセキュアストレージを使用し、メタデータ・設定・履歴はアプリ専用領域にも保存します。 Android 1.0.3（29885088 / DeployGate #166）と同じ停止変更を含む後続版では、外部への自動診断送信を停止しています。旧版の挙動と端末内ログ・手動共有の取扱いは 2.2 項をご参照ください。

1. はじめに

FileSync(以下「本アプリ」)は、ユーザーのプライバシーを最重要視しています。 本プライバシーポリシーは、本アプリがどのような情報をどのように取り扱うかを説明します。 本アプリは、Google Drive / Dropbox / WebDAV 対応ストレージ(Koofr / pCloud 等)、SFTP / FTP サーバー、USB ストレージ、端末内ローカルストレージを統合管理するファイルマネージャーです。

2. 収集する情報

2.1 広告・追跡のために収集しない情報

以下の情報を広告・追跡目的で収集しません。診断ログの版ごとの取扱いは次項に記載します。

  • 個人を特定できる情報(氏名・住所・電話番号・メールアドレス等)
  • 操作したファイルの本体データ
  • 位置情報
  • 広告ID等のトラッキング識別子(IDFA / GAID)
  • 広告目的の利用履歴・行動アナリティクス

本アプリは広告・行動分析目的の外部アナリティクス基盤(Google Analytics / Firebase Analytics / Amplitude 等)を使用していません。

2.2 クラッシュレポート・診断ログ

Android 1.0.3（ビルド 29885088 / DeployGate #166）と、同じ診断送信停止の変更を含む後続版では、クラッシュレポート・診断ログ・使用統計・パフォーマンス情報を外部へ自動送信しません。 iOS もこの変更を含む配布版から対象となり、既存の配布版へ自動適用されるものではありません。

この変更前の版（DeployGate #165 等）は、Sentry へエラー内容、端末・OS・アプリバージョン、発生時刻、スタックトレース等を自動送信する場合があります。 旧版のマスキングは、すべてのファイル名・パス等の匿名化を保証するものではありません。更新や端末内データの削除によって、過去に送信済みの診断情報が削除されることはありません。

診断ログは端末内にも保存されます。ログの書き出しと外部への自動送信は別の処理です。ユーザーがログを手動で共有する場合は、内容と共有先を確認してください。 OS 自身や接続先サービスが行う診断・アクセスログの取扱いは、それぞれの設定・ポリシーに従います。

2.3 端末内に保存される情報

以下の情報を端末内に保存します。接続時には必要な認証情報等を選択したサービスへ送信します。端末内の診断ログと旧版の診断送信は前項のとおりです。

  • 各クラウドサービスの OAuth アクセストークン / リフレッシュトークン
  • WebDAV / SFTP / FTP の 接続先情報・認証情報(ユーザー名・パスワード・SSH鍵)
  • ファイル一覧(メタデータ)の一時キャッシュ
  • 同期設定・表示設定・お気に入り
  • バックアップ・転送ジョブの履歴、端末内の診断ログ

認証情報には iOS Keychain や Android のセキュアストレージを使用します。メタデータ・設定・履歴は OS が隔離するアプリ専用領域のデータベース等にも保存し、その全体をアプリ独自に暗号化しているわけではありません。

2.4 ユーザー操作により外部送信される情報

ユーザーがバックアップ・アップロード・転送機能を使用した場合に限り、対象ファイルがユーザー自身が指定した送信先(クラウドストレージ・WebDAV / SFTP / FTP サーバー等)へ送信されます。 これらは ユーザーが明示的に選択したサービスとの直接通信であり、開発者のサーバーを経由しません。

3. 第三者サービス

本アプリは、ユーザーが接続を選択した以下のサービスと ユーザー名義で直接通信します。本アプリ開発者は、これらのサービスにユーザーの代理として接続するのみで、認証情報は選択した接続先の認証に使用します。旧版の診断送信は前述のとおりです。

  • Google Drive(Google LLC のプライバシーポリシー)
  • Dropbox(Dropbox のプライバシーポリシー)
  • pCloud(pCloud のプライバシーポリシー)
  • WebDAV / SFTP / FTP サーバー(ユーザーが指定する任意のサーバー)

これらのサービスにおけるデータの取り扱いは、それぞれのサービス提供者のプライバシーポリシーに従います。旧版の診断送信には Sentry が使用される場合があります。対象版と送信停止の範囲は 2.2 項をご参照ください。

4. アクセス権限

本アプリが要求する OS 権限と、その用途は以下のとおりです。権限の要求時期は OS やアプリの初期化・機能の設定状態によって異なります。

  • 写真ライブラリ: 写真・動画の自動バックアップ機能のため
  • ローカルネットワーク: WebDAV / SFTP / FTP サーバー接続のため
  • Face ID / Touch ID / 生体認証: アプリロック機能のため
  • ファイル共有・ドキュメントブラウザ: ファイルのインポート・エクスポートのため
  • バックグラウンド処理: OS が許可する範囲でバックグラウンド転送を行うため。アプリ終了後の継続を保証するものではありません
  • 外部ストレージ(Android): USB / SDカード等のローカルファイルアクセスのため

5. Cookie・トラッキング

本アプリは Cookie を使用しません。また、以下の機能を一切使用していません。

  • 広告識別子(IDFA / GAID)の収集
  • クロスサイト・クロスアプリのトラッキング
  • 第三者広告ネットワークへの接続
  • App Tracking Transparency(ATT)対象の追跡行為

6. セキュリティ

  • 認証情報・トークンには OS のセキュアストレージを使用します
  • 通信の暗号化は接続方式・設定に依存します。HTTPS / SFTP は暗号化されますが、平文 FTP や HTTP 接続では通信内容が暗号化されないため、機密情報の転送には暗号化された接続を選んでください
  • 生体認証(Face ID / Touch ID / 指紋)によるアプリロック機能を提供します
  • SFTP は公開鍵認証にも対応します

7. 子供のプライバシー

本アプリは13歳未満の子供から意図的に個人情報を収集することはありません。

8. 国際的なデータ転送

ファイル本体は開発者サーバーを経由しません。ユーザーが選択したクラウドサービス等は海外にデータを保管する場合があります。旧版で Sentry に送信済みの診断情報も海外に保管される場合があります。詳細は各サービスのプライバシーポリシーを参照してください。

9. GDPR / CCPA への対応

情報の取扱いや削除に関するご質問は、下記のお問い合わせ先へご連絡ください。 端末内の認証情報とアップロード済みファイルの削除については、次項をご参照ください。

10. データの削除

10.1 認証情報・接続設定

  • 各サービスの「ログアウト」または「接続解除」操作で、対応するトークンが端末から削除されます
  • アンインストール後も iOS Keychain 等に認証情報が残る場合があります。アンインストール前に接続解除してください
  • サービス側の認証管理画面からもアプリへのアクセス許可を取り消せます。端末内の削除だけでは、送信済みの診断情報は削除されません

10.2 アップロード済みのファイル

各クラウド/サーバー側の管理画面または公式アプリから直接削除してください。本アプリ内からの削除操作にも対応しています。

11. プライバシーポリシーの変更

本プライバシーポリシーに重要な変更がある場合は、アプリ内通知または App Store / Google Play のアップデート情報、および本ページの「最終更新日」の更新によりお知らせします。

12. お問い合わせ

プライバシーに関するご質問やご不明な点がございましたら、本アプリの GitHub リポジトリの Issues よりお問い合わせください。

  • 連絡窓口: GitHub Issues
  • 運営: FileSync 開発チーム(個人開発者)

13. まとめ

FileSync は「ローカルファースト・プライバシー・バイ・デザイン」の原則に基づいて開発されています。

  • 認証情報は選択した接続先の認証に使用します。外部への自動診断送信を停止した対象版は 2.2 項のとおりです
  • ファイル本体は開発者サーバーを経由しません
  • 認証情報は端末内のセキュアストレージで保護
  • データの販売は行いません。選択した接続先への送信と、端末内ログ・旧版の診断送信は上記のとおりです
  • 広告・追跡なし
