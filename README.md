# nurupoga.github.io

[nurupoga.net](https://nurupoga.net/) の静的サイト。GitHub Pages が `main` のルートを公開します。

## お問い合わせフォーム

- `index.html#contact` から FormSubmit の HTTPS エンドポイントへ通常のフォーム POST で送信し、`oota401@gmail.com` で受信します。
- お名前・返信先メール・件名・本文は必須、会社名は任意です。ブラウザ標準の必須／メール形式チェックを使用します。
- FormSubmit 標準の reCAPTCHA を有効のまま使用し、`_honey` も設置しています。
- 受付後は `contact-thanks.html` に戻ります。受付表示は受信箱への配達を保証するものではありません。
- 個人情報の利用目的と FormSubmit の利用をフォームに表示しています。メールアプリ不要で送信できます。障害時の直接メールリンクもあります。

### 初回の有効化（サイト所有者）

1. 公開サイトのフォームから、実在する返信先を入力して初回送信します。
2. `oota401@gmail.com` に届く FormSubmit の確認メールを開き、送信先を有効化します。迷惑メールも確認してください。
3. 有効化後、もう一度テスト送信し、受信と返信先を確認します。未有効化の初回データが配達される前提では運用しないでください。
4. 確認メールに含まれる匿名エンドポイントを使う場合は、`form action` をそのエンドポイントへ変更します。

実装時点ではフォームの実送信・確認メールの発行・メールボックスでの受信確認は行っていません。有効化は所有者による確認が必要です。

公式仕様: https://formsubmit.co/ および https://formsubmit.co/documentation
